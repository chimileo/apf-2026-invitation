# Annual Planning Forum 2026 invitation

Public invitation site for the Annual Planning Forum 2026 for Planning Officers,
7–11 December 2026, Tashi Namgay Grand, Phuentsholing.

- `index.html` is the whole site. Event details and the agenda are in the `EVENT` and `AGENDA` objects near the top of the script.
- To add Forum photos: put JPG files in `photos/` and list them in `photos.json`, for example
  `[{"src": "photos/day1-opening.jpg", "caption": "Opening ceremony"}]`.
